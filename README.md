# 🧠 Breast Cancer Prediction using PCA & Logistic Regression

This project focuses on predicting breast cancer diagnosis using Machine Learning techniques.  
The dataset is preprocessed, scaled, reduced using PCA, and classified using Logistic Regression.

---

# 🚀 Features

- Data preprocessing using Pandas
- Feature scaling with StandardScaler
- Dimensionality reduction using PCA
- Classification using Logistic Regression
- High prediction accuracy (~98%)

---

# 📂 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn

---

# ⚙️ Machine Learning Workflow

```text
Dataset
→ Data Cleaning
→ Feature Scaling
→ PCA
→ Logistic Regression
→ Prediction
```

---

# 📊 PCA

Principal Component Analysis (PCA) is used to reduce the number of features while preserving maximum variance and important information from the dataset.
